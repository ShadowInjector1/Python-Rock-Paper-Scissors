# Python-Rock-Paper-Scissors
A simple Python Rock Paper Scissors game where players compete against the computer using random choices.


🎮 Python Rock Paper Scissors Game


📌 Project Overview
A Python-based Rock Paper Scissors Game where players compete against the computer by choosing Rock, Paper, or Scissors.

The computer randomly selects its choice using Python's Random Module, and the winner is determined based on the game's rules.

This is my third Python project, built to practice random number selection, conditional statements, user input, and basic game logic.


🚀 Features
Allows players to choose Rock, Paper, or Scissors.
Generates a random choice for the computer.
Determines the winner based on game rules.
Detects draw situations when both choices are the same.
Handles invalid user input.
Displays the final result with a winning or losing message.


🛠️ Technologies Used
Python 3
Random Module
Conditional Statements (if-elif-else)
User Input
String Methods
Logical Operators


📂 How to Run
Make sure Python 3 is installed on your system.
Clone this repository:

bash
git clone https://github.com/your-username/python-rock-paper-scissors.git
Navigate to the project folder:

bash
cd python-rock-paper-scissors
Run the Python script:

bash
python main.py
